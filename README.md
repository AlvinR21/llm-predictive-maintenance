# LLM for Predictive Maintenance
This is a hybrid system combining an LSTM-based Remaining Useful Life (RUL) predictor with a Retrieval-Augmented Generation (RAG) pipeline for explainable predictive maintenance of industrial equipment.
## Project Overview
This is my Bsc (Hons) Computer Science final year project. The system predicts the Remaining Useful Life of turbofan engines from sensor data (using NASA's C-MAPSS dataset) and generates maintenance recommendations grounded in a Retrieval-Augmented knowledge base.
## Tech Stack
**Python 3.11**
**PyTorch** - LSTM RUL predictor
**FAISS + sentence-transformer** - document retrieval
**Ollama + Mistral 7B** - language model
**LangChain** - RAG orchrestration
**Streamlit** - web interface
